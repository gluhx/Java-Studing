*Проект №1. Симулятор маятника*

Пользователь захватывает груз мышью, переносит в произвольное допустимое положение и отпускает. Программа рассчитывает движение по уравнениям, а не по заранее заданной анимации.

Этапы реализации: идеальный маятник → затухание → управление параметрами → графики угла, скорости и энергии → сравнение численных методов → двойной маятник как дополнительная задача.

*Проект №2. Двумерная молекулярная динамика*

Частицы свободно перемещаются в замкнутой области и сталкиваются друг с другом и со стенками.

Этапы: одна частица → две частицы → сотни → тысячи → пространственная оптимизация → графики энергии и распределения скоростей → эксперименты с температурой и плотностью.

Для модели идеального газа отдельно разберём статистическую физику и распределение Максвелла.
