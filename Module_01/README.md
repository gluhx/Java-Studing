# Модуль 1. Java Core на продвинутом уровне

1.	JVM, JDK, JRE, байткод, JIT-компиляция, отличие Java от Python и C++
2.	Типы данных, ссылки, передача параметров, неизменяемость объектов, equals и hashCode
3.	ООП углублённо: наследование, композиция, полиморфизм, интерфейсы, sealed classes, records
4.	Generics, type erasure, wildcard, PECS
5.	Коллекции: List, Set, Map, Queue, внутреннее устройство HashMap
6.	Лямбды, функциональные интерфейсы, Stream API, Optional
7.	Исключения, обработка ошибок, AutoCloseable, try-with-resources
8.	Работа с файлами: NIO.2, Path, Files, сериализация, бинарные форматы
9.	Управление памятью, стек, куча, GC, профилирование JVM

Маленькие задачи:

1. Реализовать собственный динамический массив с автоматическим расширением.
2. Создать LRU-кэш с ограничением размера.
3. Написать программу поиска дубликатов файлов по хешам.
4. Реализовать обобщённый класс матрицы с операциями над элементами.
5. Написать анализатор текстового файла: частоты слов, сортировка, фильтрация.
6. Создать систему обработки событий на интерфейсах и лямбдах.
7. Сравнить производительность ArrayList и LinkedList в разных сценариях.
8. Реализовать чтение и запись собственного бинарного формата.

Лабораторная: собственная библиотека математических векторов, которую позже используем в физических симуляциях.
